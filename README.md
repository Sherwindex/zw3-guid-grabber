# ZW3 GUID Grabber

A simple and lightweight tool to quickly retrieve your Windows **Machine GUID** for ZW3.

![Preview](https://repository-images.githubusercontent.com/1379023293/466cc4f7-f9be-4cfa-abdd-b066b8e07c28)

### How to Use

1. Download the latest release:  
   **[Download ZW3_GUID_Grabber.bat](https://github.com/Sherwindex/zw3-guid-grabber/releases/download/v1.0.0/ZW3_GUID_Grabber.bat)**
2. Double-click the file
3. Your Machine GUID will automatically be copied to the clipboard

### Features

- Reads the MachineGuid from the Windows registry
- Copies it directly to your clipboard
- Fully offline — nothing is sent anywhere
- Completely open source (right-click → Edit to view the code)

> **Note:** Santahunter & Wiizard plan to add a built-in button to retrieve the system GUID in a future V4 release.
